# port-kill-npm

npm distribution wrapper for [**port-kill**](https://github.com/Boughzala-ayoub/port-kill) — a fast cross-platform CLI to find and kill processes listening on a given TCP/UDP port.

```bash
npx port-kill-npm 3000
```

See the main repository at [Boughzala-ayoub/port-kill](https://github.com/Boughzala-ayoub/port-kill) for full documentation, source code, and prebuilt binaries.
